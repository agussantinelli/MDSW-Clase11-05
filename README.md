<h2>🚀 Propósito del Proyecto</h2>
<p>
  Este repositorio contiene la implementación de una <b>String Calculator</b> desarrollada bajo la disciplina de <b>Test-Driven Development (TDD)</b>. El objetivo es resolver de forma incremental las funcionalidades requeridas, asegurando la calidad del código mediante pruebas unitarias exhaustivas y rotación de roles entre los integrantes.
</p>

<h2>🛠️ Protocolo de Desarrollo (Incremental)</h2>
<p>Para cada funcionalidad solicitada, el equipo sigue este flujo de trabajo obligatorio:</p>

<ol>
  <li><b>🧪 Diseño de Pruebas:</b> Se definen los casos de prueba necesarios antes de escribir una sola línea de lógica de negocio.</li>
  <li><b>🔴 Ciclo Red:</b> Se codifica un (1) solo test a la vez y se verifica que falle.</li>
  <li><b>🟢 Ciclo Green:</b> Se implementa el código mínimo necesario para que el test pase.</li>
  <li><b>📤 Sincronización:</b> Una vez que el test es exitoso, se realiza el commit y push al repositorio.</li>
  <li><b>🔄 Rotación de Roles:</b> Se cambia el programador encargado para el siguiente test de la funcionalidad.</li>
</ol>


<br>

<h2>⚠️ Notas de Entrega</h2>
<ul>
  <li><b>Notificación de Avance:</b> Al completar todos los tests de una funcionalidad específica, se notificará a la cátedra para recibir los requerimientos del siguiente hito.</li>
  <li><b>Compatibilidad:</b> El código se mantiene bajo estándares de arquitectura limpia y modular.</li>
</ul>
